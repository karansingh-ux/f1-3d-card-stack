# F1 3D Card Stack Hero

An interactive 3D card stack hero experience inspired by Oliver Bernotat, showcasing iconic Formula 1 moments (2018 - 2024) in 1080p high definition.

## Features

- **3D Card Stacking Animation:** Staggered physical pile assembly powered by smooth quintic mathematical easing (`smootherstep`).
- **Seamless Carousel Transition:** Transitions fluidly from a 3D perspective stack into an interactive horizontal carousel.
- **Calibrated Scroll Dynamics:** 1 scroll gesture moves strictly 1 frame, absorbing trackpad and mouse wheel inertia.
- **Minimal Top Sound Control:** Top-right glassmorphic icon-only button with keyboard shortcut (`M`) for authentic track audio.
- **High-Definition Media:** 1080p broadcast clips with synchronized playback and dynamic preloading.
